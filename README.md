# PBRoboticos — Material da Disciplina · Prof. Dácio (INFNET 2026.2)

Repositório **público de material** do Projeto de Bloco: Sistemas Robóticos — consulta permanente dos alunos. Atualizado a cada aula: consulte pelo navegador ou clone e rode `git pull` semanalmente:

```bash
gh repo clone Prof-Dacio-INFNET/PBRoboticos_prof_dacio
```

## Estrutura

- `aulas/` — por aula: roteiro, PDF da apresentação e arquivos usados em sala (ex.: `etapa01-aula01/`)
- `tutoriais/` — guias de setup e uso (WSL2 + ROS 2 Humble, git/GitHub Classroom, OpenCV, Gazebo, MetaDrive…)
- `exemplos/tp1…tp5/` — códigos demo por TP (pacotes ROS 2 prontos para rodar)
- `recursos/` — links, cheatsheets e pequenos arquivos de apoio

## Regras de entrega (resumo — o oficial está no Moodle)

**A entrega oficial de todo TP é no MOODLE** (ZIP de códigos + PDF + links). O repositório individual `projeto-pb-<usuario>` é auxiliar (desenvolvimento + tag `tpN` para correção do código) e critério de avaliação.

**Requisitos:** Ubuntu 22.04 (WSL2 ou nativo) + ROS 2 Humble + Python 3.10 — ver `tutoriais/`.
